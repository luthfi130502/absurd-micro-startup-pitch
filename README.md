## The pitch

> For $0.40 a click, Rent-a-Click sends a human to press 'I am not a robot'
> for AI agents too lazy to solve their own captchas, with a nine-second
> guarantee or the click is free.

The joke is narrow — a per-click human captcha-pressing service, priced like a
vending machine — but the business is real: agents already pay humans to clear
the exact checkboxes they cannot, and a speed guarantee with a free-failure
clause is a plan a buyer can price.

## How to run

```sh
python3 main.py
```

This writes the pitch (UTF-8, 176 characters, exactly one sentence) to
`/output/entry.txt`. The script self-checks the deliverable gate
(1–200 characters, not whitespace-only, one sentence) before writing.
